# Audio credits

Every sound in this folder comes from a Kenney pack published under the
Creative Commons Zero (CC0 1.0) public domain dedication. Each pack's bundled
`License.txt` file says "License: (Creative Commons Zero, CC0)" and links to
https://creativecommons.org/publicdomain/zero/1.0/.

## Packs

| Pack             | Source                                  | License  |
| :--------------- | :-------------------------------------- | :------- |
| Interface Sounds | https://kenney.nl/assets/interface-sounds | CC0 1.0 |
| Impact Sounds    | https://kenney.nl/assets/impact-sounds  | CC0 1.0  |
| RPG Audio        | https://kenney.nl/assets/rpg-audio      | CC0 1.0  |
| Music Jingles    | https://kenney.nl/assets/music-jingles  | CC0 1.0  |

All four packs are by Kenney (https://kenney.nl). Credit isn't required, but
the packs ask for it, so it's given here.

## Files

| File                | Plays for                     | Pack             | Original file                        |
| :------------------ | :---------------------------- | :--------------- | :----------------------------------- |
| `cast.ogg`          | A mob casts a spell           | Interface Sounds | `Audio/pluck_001.ogg`                |
| `hit.ogg`           | A player's spell hits an enemy | Impact Sounds   | `Audio/impactPunch_medium_000.ogg`   |
| `enemy-death.ogg`   | An enemy dies                 | Impact Sounds    | `Audio/impactSoft_heavy_000.ogg`     |
| `player-damage.ogg` | An enemy hurts the player     | Impact Sounds    | `Audio/impactPunch_heavy_000.ogg`    |
| `player-death.ogg`  | The player dies               | Interface Sounds | `Audio/error_006.ogg`                |
| `wave-start.ogg`    | A wave starts                 | RPG Audio        | `Audio/drawKnife1.ogg`               |
| `run-music.ogg`     | Music during a run, looped    | Music Jingles    | `Preview.ogg`                        |
| `game-over.ogg`     | Music when the run ends       | Music Jingles    | `Audio/8-Bit jingles/jingles_NES00.ogg` |

The files are copied unchanged and renamed for the event they play for.
